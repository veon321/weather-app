# Responsive Weather App with Extended Forecast

A sleek, modern, and fully interactive frontend Weather application that provides real-time weather conditions alongside hourly and daily forecasts. Built with vanilla technologies, it features a fluid two-column dynamic layout, beautiful glassmorphism effects, and highly crisp colors.
